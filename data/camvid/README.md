# Dataset CamVid (Cambridge-driving Labeled Video Database)

Dataset ini digunakan untuk modul **Semantic Segmentation menggunakan Deep Learning**.

## Pranala Unduhan Resmi:
- **Citra Masukan (701 frames)**:  
  http://web4.cs.ucl.ac.uk/staff/g.brostow/MotionSegRecData/files/701_StillsRaw_full.zip
- **Anotasi Piksel (Pixel Labels)**:  
  http://web4.cs.ucl.ac.uk/staff/g.brostow/MotionSegRecData/data/LabeledApproved_full.zip
- Kaggle: https://www.kaggle.com/datasets/carlolepelaars/camvid

## 11 Kelas Target yang Digunakan:
1. Sky
2. Building
3. Pole
4. Road
5. Pavement
6. Tree
7. SignSymbol
8. Fence
9. Car
10. Pedestrian
11. Bicyclist
*(+ Kelas 0 / Void untuk piksel tak berlabel / background yang tidak masuk kategori)*

## Pembagian Data:
- Train: 60%
- Validation: 20%
- Test: 20%
